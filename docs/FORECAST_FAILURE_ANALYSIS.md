# 예측 실패 분석

공개 문서에는 개인 사례, 실제 시각·수치·예측을 기록하지 않는다. 실제 현상은 비공개 V2.1 보고서와 예측 파일에서만 확인한다. 아래는 **확인할 실패 유형과 가설**이지 특정 사고가 발생했다는 주장이나 합성 실측 사례가 아니다. V2.2는 저장된 V2.1 24h 예측의 불확실성 및 별도 persistence replay를 분석했으나, 저장된 V2.1 후보 모델은 없다.

| 관측할 현상 | 가능한 공정 원인 | 필요한 데이터 근거 | 가능한 모델 실패 메커니즘 | 검증할 개선 가설 |
|---|---|---|---|---|
| 실제 급등 저예측 | 유입 충격 또는 처리상태 변화 | 이전 유입, 유량, 분석 도착, 운전 상태 | 평균 회귀·hybrid 희석 | 사전 정의 이벤트에서 지연 특성과 탐지율 비교 |
| 실제 하락을 늦게 반영 | 부하 감소 또는 처리 회복 | 유입 추세, 방류 채취·보고 시각 | 지연된 기준값에 과도하게 의존 | 동일 가용 시각의 direct/delta 비교 |
| 정상 구간 과대예측 | 일시적 입력 이상 또는 운전 변화 | 센서 품질·점검 기록 | 잡음과 상관관계의 과학습 | 동일 기간 persistence 비교 및 false alarm 평가 |
| persistence보다 큰 오차 | 공정 원인은 특정 불가 | 일치 origin별 두 예측, 정답과 수신 시각 | 유효하지 않은 변화 신호 학습 | 결측 상태·운전 regime별 paired 차이 |
| 고부하 오차 증가 | 부하 급증·처리 여유 저하 가능 | 유량·단위·유입 및 운전 이력 | 훈련 지원 범위 밖 입력 | 개발기준 고부하군을 독립 기간에서 평가 |
| 학습과 다른 TOC 수준 | 유입·운전 변화 가능 | 시간대별 분포와 변경 이력 | 수준 이동에 따른 편향 | direct/delta 수준별 bias 비교 |
| 결측·계측 지연 | 점검·통신·분석 지연 가능 | 원본 품질코드, 채취·보고·수신 이력 | 오래된 값 또는 잘못된 이용시각 | 결측/age별 오류와 실제 지연 적용 비교 |

사례별 원점에서 예측 전에 이용 가능했던 값만 재구성하고 정답, 결측, 수정 및 censoring을 기록한다. 현장 이력 없이 원인을 확정하지 않는다. 이미 확인한 최종 테스트의 사례를 사용해 후보를 조정하지 않는다. 실패의 빈도와 선택 기준, 이벤트 수를 함께 기록하고 독립 기간에 가설을 확인한다.
